To-Do List Application
Description
A command-line task management application that allows users to create, view, complete and delete tasks. Tasks are stored in a JSON file for persistent storage.
Features
•	Add tasks
•	View tasks
•	Mark tasks as completed
•	Delete tasks
•	Persistent JSON storage
•	Basic error handling
Technologies
•	Python
•	JSON
•	File handling
How to Run
python todo.py
Skills Demonstrated
•	CRUD operations
•	JSON data storage
•	Functions
