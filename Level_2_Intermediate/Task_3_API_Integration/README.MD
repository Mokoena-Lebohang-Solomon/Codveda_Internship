API Integration
Description
A Python application that communicates with a REST API, retrieves JSON data and displays the information in a readable format.
Features
•	Sends GET requests
•	Processes JSON responses
•	Displays API data
•	Handles connection errors
•	Handles HTTP and invalid response errors
Technologies
•	Python
•	Requests
•	REST API
•	JSON
Installation
pip install requests
How to Run
python api_client.py
Skills Demonstrated
•	REST API integration
•	HTTP requests
•	JSON processing
•	Error handling
