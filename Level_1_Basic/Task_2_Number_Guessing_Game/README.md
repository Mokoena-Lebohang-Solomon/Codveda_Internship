Number Guessing Game
Description
A simple Python command-line game where the computer randomly selects a number between 1 and 100. The user has a limited number of attempts to guess the correct number.
Features
•	Random number generation
•	Multiple guessing attempts
•	"Too high" and "Too low" feedback
•	Input validation
•	Maximum attempt limit
Technologies
•	Python
•	random module
How to Run
python number_guessing_game.py
Skills Demonstrated
•	Conditional statements
•	Loops
•	User input
•	Exception handling
•	Random number generation
