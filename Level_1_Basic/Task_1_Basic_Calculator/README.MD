Basic Calculator
A simple command-line calculator built with Python. This project demonstrates basic Python programming concepts such as functions, input validation, exception handling, match-case, and program termination.
Features
•	Add two numbers
•	Multiply two numbers
•	Divide two numbers
•	Subtract two numbers
•	Handles invalid user input
•	Handles division by zero
•	Allows the user to exit the calculator
Technologies
•	Python 3
•	Standard Python libraries
How to Run
1.	Clone or download the repository.
2.	Open the project folder in a terminal.
3.	Run:
python calculator.py
4.	Enter two numbers and select an operation from the menu.
Example
Enter first number: 10
Enter second number: 5

Press 1 to Add two numbers.
Press 2 to Multiply two numbers.
Press 3 to Divide two numbers.
Press 4 to Subtract two numbers.
Press 5 to Close calculator.

Enter your choice: 1

Sum of the 10 and 5 is 15
