N-Queens Problem
Description
A Python implementation of the classic N-Queens problem. The program uses backtracking to place N queens on an N × N chessboard so that no two queens can attack each other.
Features
•	Supports different board sizes
•	Uses recursive backtracking
•	Checks rows, columns and diagonals
•	Displays the solution as a 2D board
Technologies
•	Python
•	Recursion
•	Backtracking
•	Algorithms
How to Run
python n_queens.py
Enter the number of queens when prompted.
Example
Enter the number of queens: 8

A solution was found for 8 queens.
