File Encryption and Decryption
Description
A Python command-line application that encrypts and decrypts files using Fernet symmetric encryption.
Features
•	Generate an encryption key
•	Encrypt files
•	Decrypt files
•	Save encrypted files separately
•	Handle invalid files and keys
Technologies
•	Python
•	Cryptography
•	Fernet encryption
Installation
pip install cryptography
How to Run
python encryption.py
Follow the menu options to generate a key, encrypt a file or decrypt an encrypted file.
Security Note
The generated secret.key file must be kept private. It should not be uploaded to GitHub.
Skills Demonstrated
•	File handling
•	Symmetric encryption
•	Cryptographic key management
•	Exception handling
